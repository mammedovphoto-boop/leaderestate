# Leader Estate

Сайт агентства недвижимости Leader Estate (Ашхабад). Статический сайт без сборки, три языка: RU / TM / EN.

- `js/config.js` — телефон, WhatsApp, Instagram, язык по умолчанию, районы, валюты.
- `js/i18n.js` — все тексты на трёх языках.
- `js/app.js` — логика формы заявки.
- `css/styles.css` — оформление.

Публикация: Cloudflare Pages, Framework preset — None, Build command и Build output directory пустые.
